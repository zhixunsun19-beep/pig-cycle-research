# derived_metrics.json 字段映射（以当前文件为准）

> 不是预设「28 字段」，而是对 `data/processed/derived_metrics.json` 实际键的逐项枚举。
> 所有字段由 `scripts/build_derived_metrics.py` 从 `data/raw/*.json` 生成，可复算。

## 0. 通用约定

- 输入：`data/raw/<code>.json` 的 `reports.fzb / lrb / llb`，每期带
  `rType`（合并期末）、`is_audit`（是否审计）、`publish_date`（披露日）。
- 单位：接口为**元**，输出统一为**亿元**（`/1e8`，`round(...,2)`）。
- 期间：资产负债表为**期末时点**；利润表/现金流量表为**年内累计**。
- 单季：`Q2 = 半年累计 − Q1 累计`；`Q3 = 前三季累计 − 半年累计`；`Q1` 累计即单季。
- 缺失：接口 `null`/空串 → `null`，**不按 0**；求和跳过 `null`，全空输出 `null`。
- 重复科目：同名 `item_title` 取首次出现（接口存在重复行）。

## 3. 有息负债（4 个期间）

| 字段 | 公式 |
|---|---|
| `有息负债_2026Q3` | 见下，期间 20260930 |
| `有息负债_2026Q2` | 20260630 |
| `有息负债_2025Q3` | 20250930 |
| `有息负债_2025年末` | 20251231 |

每个对象 11 个键：

- `短期有息负债` = 短期借款 + 应付短期债券 + 一年内到期的非流动负债
- `长期有息负债` = 长期借款 + 应付债券
- `有息负债合计` = 短期有息 + 长期有息（不含租赁负债、长期应付款）
- `净有息负债` = 有息负债合计 − 货币资金
- `资产负债率_pct` = 总负债 ÷ 总资产 × 100
- `流动比率` = 流动资产 ÷ 流动负债
- `有息负债率_pct` = 有息负债合计 ÷ 总资产 × 100
- `短期有息占比_pct` = 短期有息 ÷ 有息负债合计 × 100
- `现金覆盖短期有息_pct` = 货币资金 ÷ 短期有息 × 100
- `租赁负债(单列)`、`长期应付款(单列)`

**缺失行为（与代码一致，如实说明）**：

- 有息负债各分量（短期借款/应付短期债券/一年内到期非流动负债；长期借款/应付债券）
  全部为空时，`短期有息负债`/`长期有息负债`/`有息负债合计` 输出 **None**，不按 0 计；
  部分缺失时按现有分量求和（None 跳过）。整个期间缺失同理输出 None。
- **例外**：`资产负债率_pct` 的分子（总负债）缺失而总资产存在时按 0 参与（得 0%）；
  `流动比率` 在流动负债存在、流动资产缺失时按 0 参与得 0。这两处未改为 None，
  如需收紧须另行评估并补测试。

## 4. 融资成本与现金流

`融资成本`：

- `前三季度利息费用_亿元` ← 利润表「利息费用」
- `年化利息费用_亿元` = 利息费用 × 4/3
- `平均有息负债_亿元` = (2026Q3 + 2025年末) ÷ 2
- `估算融资成本_pct` = 年化利息费用 ÷ 平均有息负债 × 100
- `广义平均有息负债_亿元` = 均值（有息合计 + 租赁负债 + 长期应付款）
- `广义估算融资成本_pct`、`租赁负债占广义有息_pct`、`主口径失真`（≥15% 为真）
- `前三季度财务费用_亿元` ← 利润表「财务费用」

`现金流`：

- `前三季度经营/投资/筹资_亿元` ← 现金流量表累计
- `资本开支_亿元` ← 购建固定资产、无形资产和其他长期资产所支付的现金
- `自由现金流_亿元` = 经营 − 资本开支
- `销售回款_亿元`、`取得借款_亿元`、`偿还债务_亿元`
- `单季现金流_亿元` = {Q1, Q2, Q3} × {经营, 投资, 筹资}，按单季差分

## 6. 与旧生成器的差异

`scripts/compute_metrics.py`（旧版）只输出 §2–§4 的 17 个字段，不含 §5 的 11 个扩展字段；
它仍保留作为历史参考，但**不得**用于 v3 计算。新生成器输出 28 字段，
与发布版的唯一数值差异是 §5.1 的归母净利润修正（30 个字段位置），其余逐字段一致。

## 7. 已知提取缺口（继承自旧版，本轮未改提取逻辑）

以下两处导致**结构上存在的字段值为 null**，28 个字段结构完整但个别取值不完整；
均未被评分（`compute_v3.py`）与图表（`chartgen/`）使用：

1. **利息收入大量为空**：`table()` 对同名科目取首条（`item_title` 重复时首条常为空、
   后续为实际值），导致 15 家 × 多数期间 `利润表_*["利息收入"]` 为 null
   （仅 1 家有值）。累计 112 个「首条空、后续有值」实例。
2. **其他应收款 2026Q3 系统性为空**：接口另有「其他应收款(合计)」科目且 15 家均有值，
   但映射只取裸科目「其他应收款」，未回退合计。

因此不得宣称“字段取值已完整”；如需修复应改提取规则并补回归测试，另行评估。
