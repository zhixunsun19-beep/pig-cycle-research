# 数据字典（data-dictionary.md）

| 字段 | 定义 | 来源层 | 单位 |
|---|---|---|---|
| 完全成本 | 养 1kg 生猪承担的全部成本（含折旧/期间费用/财务费，各公司口径见表内标注） | 公司披露（调研纪要/互动平台），一手或二手 | 元/kg |
| 现金成本 | 继续养猪实际支付的现金支出（不含折旧等非现金项） | 仅 3 家有读数（东瑞一手、华统二手、牧原待核实） | 元/kg |
| 短期有息 | 短期借款＋应付短期债券＋一年内到期非流动负债 | 一手三表测算 | 亿元 |
| 有息合计(主口径) | 短期有息＋长期有息；租赁负债/长期应付款单列 | 一手三表测算 | 亿元 |
| 净有息 | 有息合计−货币资金（未扣受限资金） | 测算 | 亿元 |
| 现金覆盖率 | 货币资金÷短期有息×100%（未扣受限资金，偏乐观） | 测算 | % |
| 集团现金跑道 | 货币资金÷月现金净消耗（情景模型） | 测算 | 月 |
| 养猪业务现金跑道 | 生猪板块自身现金消耗与造血 | 无分部现金流披露 → 无法独立测算 | — |
| 理论经营贡献增量 | 猪价+1 元/kg × 120kg × 年化出栏（静态敏感性，非盈利预测） | 测算 | 亿元 |
| 单位市值弹性 | 理论增量 ÷ 总市值（2026-11-13 收盘） | 测算＋行情 | % |
| 覆盖率 | 已评分子项权重 ÷ 总权重；<70% → 待核实区 | 测算 | % |
| 生产性生物资产 | 母猪等种猪资产账面值（产能保全代理指标） | 一手三表 | 亿元 |
| 年化出栏 | 26M1-10 累计 × 12/10（线性，口径变更逐家标注） | 一手简报＋测算 | 万头 |
| 数据级别 | 一手（公司披露）/二手（需核实原文）/测算（公式明示）/预测（机构） | 研究数据层标注 | — |
