# 关键假设与模型边界（assumptions.md）

> 本文件集中列出报告中所有**非披露事实**的假设，便于读者判断结论对假设的敏感度。
> 凡属假设的，报告中均以【测算】标注；凡属披露事实的，标注【一手】。

---

## 1. 猪价情景

| 情景 | 猪价（元/公斤） | 相对基准 |
|---|---:|---:|
| 极端压力 | 5.60 | −3.0 |
| 深度悲观 | 6.60 | −2.0 |
| 悲观 | 7.60 | −1.0 |
| **基准** | **8.60** | 0 |
| 温和复苏 | 9.60 | +1.0 |
| 强势复苏 | 10.60 | +2.0 |

**基准 8.60 的取法**：2026-11-13 全国外三元市场均价，多源区间 8.54–8.76。采信依据是与 Mysteel 2026-11-11 自繁自养头均亏损 384.27 元反推自洽：(11.4−8.6)×120kg ≈ 336 元，加期间费用后接近 384 元。媒体转引的 11.83 与官方 9 月出场价 11.05 并列存疑，未采用。

**假设**：情景期内成本不变、出栏均重 120kg、出栏量按年化固定；不模拟企业主动减产、二次育肥、疫病冲击与政策收储。

## 2. 出栏与均重

- 出栏均重 **120 公斤/头**（行业常见值，非逐家披露）；若实际均重偏离，弹性与亏损同比例变化。
- 年化出栏 = 2026 年 1—10 月累计 × 12/10，**线性外推**，未计季节性（Q4 通常偏旺，故对全年为保守估计）。
- 口径变更（温氏含/剔除仔猪、新希望生猪→商品猪、大北农控股商品肥猪、华统月度累加推算）已在图 4 与数据表中逐家标注，**不可直接同比**。

## 3. 现金跑道模型

```
年化经营现金流      = 前三季度经营现金流 × 4/3
猪价增量现金流      = Δ猪价 × 年化出栏 × 120kg ÷ 1e4
情景经营现金流      = 年化经营现金流 + 猪价增量
维持性资本开支      = 前三季度资本开支 × 4/3 × 50%
情景自由现金流      = 情景经营现金流 − 维持性资本开支
月现金净消耗        = max(0, −情景自由现金流) ÷ 12
集团现金跑道(月)    = 货币资金 ÷ 月现金净消耗
```

**假设与偏差方向**：

| 假设 | 方向 |
|---|---|
| 维持性资本开支取 50%（另一半扩产可暂停） | 对重资产企业偏乐观 |
| 货币资金**未扣受限资金** | **偏乐观**（真实可动用更少） |
| 未加回交易性金融资产 | 偏保守 |
| 未计续贷、未使用授信、资产处置、政府补助、股东支持 | 偏保守 |
| 未计主动减产（减产同时减少亏损与消耗） | 对已减产企业偏保守 |
| 经营现金流按 9 个月线性年化 | 忽略季节性 |
| 以集团合并口径计算 | **不是养猪业务独立跑道** |

**跑道不是破产倒计时**，只是「在给定猪价下、只靠账上现金能撑多久」的排序工具。

## 4. 评分假设

| 项 | 假设 |
|---|---|
| A2 现金成本 | 仅采信**一手**披露；核心池 9 家均无 → 整项未评分，**不按 0 分**，有效满分 60→50 |
| A6 2027 债务 | 12 家无法核实逐笔到期，以「短期有息余额 + 现金覆盖率」作代理并打 6 折 |
| B1 生产效率 | 仅可核实子项等权（PSY/料肉比/成活率），目标值不计入 |
| B5 管理质量 | 定性评分，依据逐条列示于评分明细 |
| 四象限阈值 | 仅 7 家合格企业（覆盖率 ≥70%、无风险上限）中位数：生存 50.56 / 弹性 53.92 |
| 待核实企业 | 唐人神、新五丰不参与阈值、不获 A–D 标签，展示可比得分仅为「已评分部分」 |
| 风险上限 | 重大持续经营/流动性风险触发综合分封顶（本轮：新五丰封顶 45 分） |

## 5. 成本口径

- **完全成本**：含折旧、期间费用、财务费用；各公司是否含代养费、是否含并购主体（如天康含羌都）逐一标注。
- **现金成本**：仅东瑞（一手）、华统（二手）、牧原（媒体转述）有读数，口径不一，**不用于跨公司打分**。
- **期间**：12 家可核实成本横跨 2026-03 至 2026-10 及季度累计，**不是同一时点排名**。
- 不使用「行业平均成本」填补缺失。

## 6. 明确不做的推断

1. 不把「规划产能」当作未来出栏。
2. 不把「集团现金流」当作「养猪业务现金流」。
3. 不把「理论增量」当作「净利润预测」。
4. 不把「线性年化」当作「全年实际出栏」。
5. 不把「审计未覆盖的调研口径」当作「已审计数据」。
