**工具限制（诚实记录）**：Chrome headless 在 Windows 上有约 500px 的最小窗口宽度，`--window-size=390` 实际 `innerWidth=500`，导致第一批 390 截图右侧看似被裁。注入探针复测 `scrollWidth == clientWidth` 在 390 / 375 / 768 / 1440 四个视口全部成立（485/485、727/727、1399/1399），**页面无水平溢出**；改用 `deviceScaleFactor=2` 窄视口渲染后，移动布局完整、无裁切、正文 16px 正常（已查看截图）。裁切是截图工具假象，不是页面缺陷。

**检查方式说明**：经过 Chrome headless 实际渲染（截图 + 打印 PDF）与注入脚本交互验证（锚点、折叠、抽屉、高亮），**未在 GUI 浏览器里做人工逐项点击**；交互逻辑由脚本 click 触发并读取 DOM/ARIA 状态确认。
