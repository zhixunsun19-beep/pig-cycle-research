1. **「15094」5 处**：全部出现在 `data/raw/*.json` 的财务数值中，例如

   正则按连续 11 位数字匹配，属结构性误报。

## 八、2026-11-19 补记（public-release-prep 分支复核）

本次为公开前复核，发现并修正一处**本扫描的覆盖缺口**：

- 原扫描（第二节）只覆盖文本文件，**未检查二进制 PDF**。复核用字节级扫描发现
  `report/report_print.pdf` 内含 12 处链接注释，URI 为
  `file:///C:/Users/<username>/Desktop/deep%20research/reports/...`（本机绝对路径 +
  Windows 用户名），系 HTML→PDF 打印时相对链接被解析为本地绝对路径所致。
- 处理：在 `public-release-prep` 分支对该 PDF 做等长字节替换
  （`C:/Users/<username>/Desktop/deep%20research` → `(redacted:000…)`），
  字节长度不变、xref 未破坏，PDF 22 页可正常打开；替换后全文件
  `15094 / C:/Users / AppData` 均 0 命中。
- 历史风险提示：该 PDF 的**旧版本 blob 仍存在于 git 历史**（v6.1 首个提交起），
  仅修改当前文件不足以消除；公开前需按「历史处理方案」决定是否重写历史或重建公开分支。
- 本节同时修正第二节「Windows 本机绝对路径 0 处 ✅」的结论范围：该结论仅对文本文件成立。
