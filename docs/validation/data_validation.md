**判断**：+36% 无一手来源，可能是早期版本沿用的其他口径（如某月同比、含仔猪口径），但现有材料无法还原，按「不得编造来源」不保留。

### 2. 计算依据（27.3% 的来历）

```
2025 全年实际出栏            = 853.69 万头        （公司月度销售简报累加）
2026 年 1—10 月累计实际出栏   = 905.75 万头        （月度简报累加）
2026 年线性年化出栏          = 905.75 × 12/10 = 1086.9 万头
年化增幅                    = (1086.9 − 853.69) / 853.69 = 27.3%
```

### 3. 最终处理

- **删除**「+36%」，改为：「正邦（2025 年实际出栏 853.69 万头，2026 年 1—10 月累计 905.75 万头线性年化 1086.9 万头，年化增幅约 27.3%，为线性估算、非全年实际同比、未计季节性）」。
- **明确标注**：线性年化是估算值，不是 2026 全年实际同比增速；未计入季节性影响。
- **全文一致性**：`+36%` 残留 0 处；`27.3%` 1 处；摘要/正文/图注/结论无矛盾。傲农「存栏 +51%」为存栏同比、有出处，与本项无关，保留。
