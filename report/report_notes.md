## 三个入口

1. **`report.html`** — 单文件，10 张图 base64 内嵌，无 CDN / 外部字体，双击即可离线阅读。页面内「点击图片」可打开 `../figures/` 下的原始 SVG 放大。
2. **`report.md`** — 正文 Markdown 源，便于 diff、检索与二次编辑。
3. **`report_print.pdf`** — 22 页打印版，图表保持矢量。

## 页面结构

- 左侧固定目录（当前章节高亮，第 8/10 章可折叠），右侧正文；
- 移动端（≤900px）目录收为顶部抽屉；
- 打印时自动隐藏目录、表头重复、避免表格行与图表被拆页。

## 检查范围限定（重要）

报告页脚标注「计算脚本校验 62/62 与结构校验通过」，其含义是：

- **包含**：报告关键数字与数据包逐项比对（62 项）、章节编号/图片存在/表格列数/占位符等结构检查；
- **不包含**：全量人工事实核对、原始公告逐条审查、来源 URL 完整性审查。

本仓库额外的可执行校验是 `scripts/verify_results.py`（60 项，实测全过），同样只覆盖数据一致性，不等于全面审计。

## 已知问题（不阻塞阅读）

1. **图 10 打印字号偏小**：11 列矩阵 + 覆盖率列，A4 竖版约 5pt；屏幕端可点击放大（矢量），建议打印时单独放大该页。
2. **待核实区两家**：唐人神覆盖率 67%、新五丰 59%，展示了可比得分但不参与正式排名与象限阈值。
3. **来源链接**：`sources/source_register.md` 中 6 条为「待补充」，另有 5 条仅登记到站点主页；均未编造具体文章 URL。

## 如何核对报告数字

```bash
cd scripts
python verify_results.py
```

会逐项验证：A2 未评分 9/9、有效满分 50/35、`final_score` 可复算、7 家最终得分、待核实企业覆盖率与象限、阈值 50.56/53.92、六情景与关键跑道。任一不符会打印具体项并返回非零退出码。
