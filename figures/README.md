## 使用说明

- **复用**：SVG 可直接插入 Word / PPT / Illustrator，文字为可编辑的 `<text>`，非路径化。
- **字体**：SVG 内声明 `Noto Sans CJK JP → Microsoft YaHei → PingFang SC` 回退栈；未装 Noto 时回退系统黑体，字形略有差异，坐标与数值不受影响。
- **颜色语义**：红=警戒/亏损，蓝=主口径，绿=安全/正向，灰=待核实或缺失；同一颜色在不同图中含义一致。
- **缺失表达**：图中凡「—」「灰色†」「空心点」均为数据缺失或未评级，**不代表 0**。
